## About

I'm a **Product Analyst working on TruLeague, a SaaS product.**

My work involves understanding user behaviour, investigating product issues, and turning observations into actionable insights.

I'm a Computer Science graduate specialising in Data Science, currently building deeper expertise in **SQL, Python, data pipelines, and cloud engineering.**

I enjoy understanding how things work — from a user's interaction with a product to the data systems behind it.

- **Data Engineering:** SQL, Python, ETL/ELT, data modelling, and automation

- **Product Analytics:** Mixpanel, Hotjar, UXCam, and data-driven decisions
